# Agent Brief: Sales Enablement

## Mission
Equip the sales team with the training, tools, and content they need to effectively sell across all segments. Accelerate ramp time and improve win rates.

## Scope
- Sales training and onboarding
- Pitch decks and presentations
- Demo preparation and guides
- Objection handling training
- Proposal templates
- Competitive intelligence for sales
- CRM/sales process optimization

## Inputs to Read
- All segment `/06_SALES_ENABLEMENT.md` files
- All segment `/04_OBJECTIONS.md` files
- `/00_platform/05_COMPETITIVE_LANDSCAPE.md`
- `/00_platform/06_PRICING_PACKAGING_ASSUMPTIONS.md`

## Outputs to Produce
| File | Responsibility |
|------|----------------|
| All segment `/06_SALES_ENABLEMENT.md` | Co-owner with Segment PMMs |
| Platform pitch deck | Owner |
| Segment pitch decks | Owner (with Segment PMMs) |
| Demo guides | Owner |
| Proposal templates | Owner |
| Training materials | Owner |

## Style Rules
- Sales-friendly, practical content
- Easy to find and use
- Keep updated based on feedback
- Include real examples and talk tracks

## Conflict Rules
- **Own**: Sales training and process
- **Co-own**: Sales enablement docs with Segment PMMs
- **Coordinate**: All PMMs for messaging accuracy
- **Report**: RevOps for process metrics

## Key Deliverables (First 30 Days)
1. Create platform pitch deck v1
2. Document demo flow per segment
3. Compile objection handling cheat sheets
4. Create proposal template
5. Run first objection handling training

## Sync Cadence
- Weekly: Sales team (feedback, needs)
- Weekly: Segment PMMs (content updates)
- Bi-weekly: RevOps (process optimization)
