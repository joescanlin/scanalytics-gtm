# Pipeline Model

## Funnel Assumptions

### Conversion Rates (Starting Assumptions)

| Stage | Definition | Conversion Rate |
|-------|------------|-----------------|
| Visitors | Unique website visitors | - |
| Leads | Demo request / form fill | 2-3% of visitors |
| MQL | Marketing qualified (right ICP, engaged) | 50% of leads |
| SQL | Sales qualified (budget, timeline, authority) | 40% of MQLs |
| Opportunity | Active deal in pipeline | 60% of SQLs |
| Won | Closed deal | 25% of opportunities |

### Average Deal Size by Segment

| Segment | Avg Annual Contract | Notes |
|---------|---------------------|-------|
| PT | $5,000 | Small clinic average |
| Senior Living | $35,000 | Single community |
| Facilities | $40,000 | Mid-size building |
| Healthcare | $150,000 | Hospital system |
| Sports | $50,000 | Single team/program |

### Sales Cycle Length

| Segment | Avg Sales Cycle | Notes |
|---------|-----------------|-------|
| PT | 3-4 months | Shorter decision chain |
| Senior Living | 6-9 months | Pilot common |
| Facilities | 4-6 months | Budget cycles |
| Healthcare | 9-18 months | Enterprise procurement |
| Sports | 4-8 months | Season-dependent |

## Pipeline Velocity Levers

### Increase Volume
- More website traffic (SEO, ads)
- More event presence
- Partner channel development
- Content marketing

### Improve Conversion
- Website CRO
- Lead qualification improvements
- Sales enablement
- Demo quality

### Increase Deal Size
- Multi-building deals
- Longer contracts
- Upsell additional features
- Portfolio expansion

### Shorten Cycle
- Pilot program standardization
- ROI tools for self-qualification
- Better discovery process
- Executive sponsorship acceleration
