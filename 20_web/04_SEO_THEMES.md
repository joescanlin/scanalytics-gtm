## Internal Linking Strategy

### Hub & Spoke Model

**Main Site Hub**
- Links to all segment sites
- "Solutions" page with segment overview
- Technology/platform content

**Segment Spokes**
- Link back to main site for company/technology
- Cross-link to related segments where relevant
  - Senior Living <-> Healthcare (fall detection)
  - PT <-> Sports (gait analysis)
  - Facilities <-> Senior Living (operations)

### Link Anchor Text Guidelines
- Use descriptive, keyword-rich anchor text
- Vary anchor text to avoid over-optimization
- Include natural contextual links in content

## Technical SEO Checklist

### Per-Site Requirements
- [ ] Unique meta titles (< 60 chars)
- [ ] Unique meta descriptions (< 160 chars)
- [ ] H1 tag structure (one per page)
- [ ] Image alt text
- [ ] Schema markup (Organization, Product, FAQ)
- [ ] XML sitemap
- [ ] Robots.txt configured
- [ ] Canonical tags
- [ ] Mobile-friendly
- [ ] Page speed optimization

### Cross-Domain Considerations
- [ ] Consistent brand signals across subdomains
- [ ] Proper subdomain vs. subfolder evaluation
- [ ] Shared analytics/tag management
- [ ] Cross-subdomain linking
