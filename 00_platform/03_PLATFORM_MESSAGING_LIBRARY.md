## Reusable Copy Blocks

### "What We Do" Block
```
Our DOE-backed, patented Smart Flooring system captures occupancy and movement
to optimize your building. Sensors embedded in our own patented underlayment
work beneath your flooring, connecting to WiFi or network infrastructure to
deliver real-time insights through an intuitive dashboard.
```

### "How It Works" Block
```
1. Install: Thin sensor layer installs beneath any flooring type
2. Connect: System connects to your WiFi or network
3. Learn: AI learns normal patterns within two weeks
4. Insight: Real-time dashboard delivers actionable analytics
```

### "Privacy" Block
```
SmartStep uses sensors printed into the underlayment beneath your flooring
to detect movement patterns. There are no cameras, microphones, or wearable
devices required, preserving privacy and dignity while delivering
comprehensive insights.
```
