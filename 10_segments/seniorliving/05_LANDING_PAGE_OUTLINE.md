# Senior Living - Landing Page Outline

## Current Page Structure (seniorliving.scanalyticsinc.com)

### Section 1: Hero
- **Headline**: "Enhance Resident Experience in Your Senior Living Community"
- **Subhead**: Value proposition about resident monitoring, fall detection, operational efficiency
- **Primary CTA**: "Request Facility Demo" (opens modal)
- **Secondary CTA**: "View Benefits" (scrolls to features)
- **Visual**: Hero image of senior living facility
- **Badge**: "Facility-Wide Monitoring" indicator

### Section 2: Video Overview
- Product demonstration video
- Fall detection visualization

### Section 3: Features
- **Section Headline**: "Facility-Wide Protection & Insights"
- **4 Feature Cards**:
  1. Fall Detection & Response
  2. Resident Monitoring
  3. Staff Alerts & Workflow
  4. Analytics & Reporting
- **Integration Panel**: "Enterprise Implementation"
  - Compatible with all commercial flooring types
  - Minimal installation disruption
  - No visible sensors or cameras
  - Enterprise-grade security & reliability
  - Integration with existing care systems
  - Dedicated implementation support

### Section 4: Installation Timeline
- Step-by-step process
- Visual timeline

### Section 5: Software Showcase
- **Two Sections**:
  1. Enhanced Resident Care (teal theme)
     - Fall Detection and Response
     - Fall Prevention & Mobility Analysis
     - Care Quality Analytics
     - Staff Dashboard
  2. Optimized Facility Operations (blue theme)
     - Staff Augmentation
     - Facilities Management
     - Security & Monitoring
     - Energy Efficiency
- Interactive feature demonstrations
- "Access Live Dashboard" CTAs

### Section 6: Feature Announcement
- New features or capabilities

### Section 7: Pricing Calculator
- **Annual Subscription Calculator**
  - Building size input
  - Number of buildings
  - Contract term
  - Dynamic pricing display
- **Installation Cost Calculator**
  - Based on 30% sensor coverage
  - One-time cost display
- **Total Investment Summary**

### Section 8: FAQ
- 6 questions:
  1. Installation process
  2. Cameras/wearables requirement
  3. Fall detection mechanism
  4. Power outage operation
  5. Nurse call integration
  6. Coverage areas

### Section 9: CTA
- Final demo request form
